# Security

## Reporting a security issue

Please do not disclose suspected security vulnerabilities in public
issues or discussions.

Contact the repository owner privately with a description of the
issue, affected area, and any steps needed to reproduce it.

## Scope

This repository contains proprietary software. Please avoid publicly
disclosing security-sensitive implementation details, credentials,
private configuration, or unpublished product information.

## Dependencies

Third-party dependencies remain subject to their respective licences
and security policies.
