# Security

## Reporting a security issue

Please do not disclose suspected security vulnerabilities in public
issues or discussions.

Contact the repository owner privately with a description of the issue,
affected area, and any steps needed to reproduce it.

Do not publicly disclose credentials, private configuration, security
controls, unpublished architecture, or other sensitive implementation
details.

## Scope

This repository contains proprietary software and may contain
commercially sensitive implementation details. Access to the public
repository does not grant permission to use, reproduce, redistribute,
commercialise, or create derivative works from the proprietary
material.

## Dependencies

Third-party dependencies remain subject to their respective licences
and security policies.
